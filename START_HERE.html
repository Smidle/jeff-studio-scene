只安装本包 addons，即可使用 46 类建筑、35 张地表纹理及学习版三位预设角色，无需共享素材库。
Install this package's addons folder to use 46 building types, 35 terrain textures and three local-study character presets. No shared library is required.

    按需复制成品场景与完整依赖；无需第二包。 / Optional: copy finished scenes and their dependencies; package 02 is not required.
