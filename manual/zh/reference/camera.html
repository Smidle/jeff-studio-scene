第三部分 · 镜头与循环

公开版 0.4.7.1 · 仅插件与说明书，不附带提取角色图片、共享素材库、案例或本地测试工程。

新建自由地图默认斜俯视 45° 正交镜头。放置主角时设置正交跟随，可撤销；已保存场景不会被自动改写。四个预设提供通用构图，投影与数值仍可主动调整。预设角色画面完整正对镜头，避免俯视时压扁；只旋转显示面，脚底、角色节点与碰撞保持原位。

先设置正式构图并应用，再进入隔离测试观察。上方“锁定角度并跟随”用于测试观察模式；不会把自由观察角度写回正式镜头。

一键镜头预设

选舞台根节点 → 镜头 → 镜头预设与预览锁定 → 选择预设 → 调整参数 → 点击右侧底部 应用镜头设置。

预设只填入构图草稿，不立即修改场景，也不改变跟随目标和边界草稿。手动修改构图后，下拉显示“自定义”；与某个预设完全一致时显示对应名称。底部的浅黄色按钮一次提交构图、投影和跟随边界，形成一次撤销。没有镜头或没有修改时按钮不可用。

底部显示“未应用修改”“已应用，请保存”或无法应用的原因。切换模块、折叠分组和普通界面刷新会保留草稿；切换场景或镜头、外部修改镜头、撤销重做会同步实际数据并提示。应用不等于保存：应用后可预览，最后按 Ctrl / Cmd + S 保存。

选择预设只填入表中 7 项构图草稿；保留跟随目标、平滑度、边界和舞台模式，不自动打开/关闭滚动、不修改渲染器或原生编辑视角。正面表示从+Z向−Z看，45°仅为俯角，不是水平偏转。正交缩放用“正交画面高度”，不是距离。案例01可直接用第1项，案例02～04仍按各自数值调整；案例05默认第2项，可切换第3或4项比较。

正交缩放调整“正交画面高度”；透视缩放主要受距离和 FOV 影响，备用正交高度不生效。景深在环境页单独设置，预设不会自动开启。

场景预览呈现已应用的设置；存在草稿时会提醒先应用。预览中的自由观察不会回写正式镜头。

查看效果：先关闭已经打开的隔离测试 → 选场景根节点 → 选择预设并应用 → 再点“预览当前场景” → WASD走动。每轮关闭预览后再换预设；不把上一次隔离副本当作新参数。Cmd+Z可撤销，Cmd+S才保存。已有工程升级addon不会自动重写场景；需要自己重新应用第2项或选择第3/4项。详见案例05。

可折叠功能分组

点击带边框的标题展开或收起。★为首次默认展开，之后记住本工程的选择。全部展开／全部收起只作用于当前页。可用Tab聚焦标题，Enter/Space切换，左/右键收起或展开。收起保留草稿和正在使用的工具／试听，不会应用或保存；跨组“应用”按钮保留在方框外。

分组 包含功能
★ 镜头预设与预览锁定 四项预设、自定义状态与预览锁定；统一在底部应用。
★ 正式镜头构图 朝向、俯角、距离、FOV、焦点高度、正交高度及投影。
跟随边界 边界开关以及X/Z起点、宽度、深度；与正式构图共用应用按钮。
循环舞台 段长、速度、暂停和接缝预览；循环参数单独应用。

逐项参数

表中初始值对应新建自由地图；已选场景显示自身保存值。

多数数值先留在面板草稿，点击对应“应用”才提交。笔刷参数在绘制时读取；导入和选择纹理等动作立即执行。应用不等于磁盘保存，最后按 Ctrl+S / Cmd+S。例外以各按钮说明为准。

操作顺序与常见误区

Scenery 是滚动容器；Characters、静态天空与相机留在根节点相应分支。段边缘需要手工做连续布局，不能假设任意地形/图片可无缝循环。检查暂停、反向与改速，关闭边界辅助线再看最终画面。

保存、退出笔刷和预览请看顶部工具栏说明。这里使用侧栏、缩略图、笔刷和原生 Inspector 完成布景，不要求用户编写 GDScript。
