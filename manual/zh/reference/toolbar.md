# 界面、素材工作台与保存

> **GitHub 公开版说明：**下文保留 0.4.6 原学习版说明。三位游戏提取角色预设、可选共享素材库与历史案例包未随公开版提供；内置建筑与地表已包含，角色可使用自己的素材。[查看分发说明](../../DISTRIBUTION.md)

**Jeff Studio 场景 0.4.6**。左侧 Godot 场景树选择对象，中央 3D 视图观察、摆放和绘制，右侧插件栏调整参数。

## 顶部与右侧

3D 视图顶部保留 **新建地图、素材工作台、当前工具**。将鼠标停在当前工具上，可查看当前场景、地形尺寸与采样信息。**Esc** 退出笔刷或摆放。

右侧品牌卡显示名称、版本、语言与主题。语言可选中文或 English；主题可选 **青竹墨绿、曜石深灰、暖纸浅色**。选择保存在本工程编辑器偏好中，不改变 Godot 自身语言或场景效果。火盆与共享库两侧的星星在面板可见时播放。

共享库状态下有 **位置…** 和 **重新检查**。前者连接工程外的共享库文件夹，后者重新读取索引并刷新列表，完成后显示检查时间。完整路径和错误原因在悬停提示中；已在另一工程设置同一位置，无需重复设置。未连接也能制作纯色地形并使用本地素材。

## 八个模块与固定应用区

导航第一行是 **地形 → 一键生成 → 素材 → 铺设**，第二行是 **角色 → 镜头 → 环境 → 音乐**。导航框下面的操作框可以滚动。点击分组标题展开／收起；“全部展开／全部收起”只影响当前模块，选择会记住。

地形、一键生成和镜头页的应用框固定在右侧底部，滚动参数、折叠分组或打开底部素材工作台时仍可操作。淡金色边框与浅黄色按钮突出主要动作；暖纸主题使用琥珀色。禁用按钮表示当前没有可提交的修改，或尚缺必要目标。其他模块在各自参数下方提供对应应用按钮。切换模块或折叠分组不会自动应用或保存。小镇蓝图摆放在切换模块时取消。

- **地形：** 最上方“地形制作引导”显示当前地形或新地图草稿。新地图用“应用：创建地图”；已有地形的纹理草稿用“应用地表设置”。
- **一键生成：** 选择风格与围墙即可预览，点击“应用到场景（新建小镇）”进入蓝图摆放：鼠标选位置，Q / E 旋转，左键确认，Esc 取消。
- **预览：** 从“镜头 → 预览当前场景”主动打开。

Tab 可聚焦模块或分组；模块用左右键切换，Home／End 到首尾。分组用 Enter／Space 切换，左／右键收起或展开。

## 素材工作台

点击顶部 **素材工作台** 打开底部面板，拖动上边缘调整高度。工作台跟随当前主题，包含三个入口：

| 入口 | 操作 |
| --- | --- |
| 预设素材 | 搜索、筛选、分页浏览；选中项准备完成后，在右侧预览并“摆放选中素材” |
| 我的素材 | 浏览自己导入共享库的条目，操作与预设相同 |
| 地表纹理 | 选择单张或整套方案；点击缩略图即选入目标层或新地图草稿，再到右侧固定应用框提交 |

模型预览按住左键旋转。皮肤选择只影响后续摆放；已有物件使用“应用皮肤”及其范围选项。地表纹理不会加入可摆放物件列表。

新建地图选择方案时，设置窗口隐藏并保留规格；选完后看右侧地形预览，再应用创建。选择过程中不生成场景。首次展开只读索引和当前页缩略图，首次选中某项才准备它的文件。

## 新地图包含什么

<a id="new-free-template"></a>

顶部和“地形 → 新建地图”的 **新建地图…** 打开同一窗口。默认自由地图、每边 64 米、每边 129 个高度点。设置规格，选择纯色或预设，再点击侧栏底部“应用：创建地图”。详细步骤见[地形](terrain.md)。

| 节点或文件 | 用途 |
| --- | --- |
| HD2D_FreeWalk / HD2D_LoopStage | 舞台根节点，保存模式、素材库、音乐库与舞台参数 |
| Terrain | 可雕刻高度和纹理权重；生成地面与碰撞 |
| Scenery → Foliage | 布景和可编辑的植物散布记录 |
| Characters → Hero | 默认角色位置；在角色页选择预设或导入动画后显示人物 |
| CameraRig | 正式镜头与跟随设置；新自由地图默认 45° 正交 |
| levels 中的 .tscn 与对应 _terrain.res | 场景及独立地形数据；同名时生成新文件名 |

基础地图不包含建筑、花田或背景音乐。继续使用对应模块布置。循环舞台保留循环演出的镜头与运行行为。

## 原生 Inspector 与控制柄

选择 Stage、Terrain、Character、CameraRig 或 Road 后，Inspector 的“在 Jeff Studio 场景中编辑”可跳到插件对应位置。Transform 中 Position 是位置，Rotation 是角度，Scale 是倍率；也可拖动 Godot 移动、旋转和缩放控制柄。道路选中后可拖曲线点及切线。

保持地形原点、Scale=1 有利于后续制作。生成的 Chunk 网格由地形数据重建，请用地形笔刷修改。植物擦除处理 Foliage 记录；普通单件在场景树中选择并删除。

## 应用、撤销、保存

1. 修改参数通常先形成草稿；点击对应 **应用** 才提交。导入立即执行，地表选择先留在草稿。
2. 地形雕刻和绘制直接生效；从按下到松开是一笔，可用 **Cmd+Z / Ctrl+Z** 撤销。重做使用 Godot 编辑菜单。
3. **Cmd+S / Ctrl+S** 保存到磁盘。应用成功不等于已经保存。
4. 另存一个 .tscn 可能仍引用同一外部地形或其他资源。需要独立变体时，备份并复制相应资源，或在 Inspector 中设为独立资源后另存。
5. 预览中的行走、临时镜头和速度不会写回源场景。关闭预览后返回制作；改过正式参数时，重新打开预览查看结果。

运行场景仍需要 addons 中的 runtime 与 shaders 文件。可停用编辑器插件，但请保留整个插件目录。

## 文件选择与操作提示

共享库位置和导入文件窗口使用 Godot 原生编辑器主题。返回、前进、上级目录和显示方式等按钮保留原生图标，不随插件主题换成空白按钮。插件自己的操作仍使用像素图标。

共享库下方的信息栏保留“操作结果＋下一步建议”。例如创建地图后提示导入角色和植物，镜头应用后提示预览、保存。普通界面同步不会立即清除消息；下一次操作或切换场景会更新它。
