第三部分 · 隔离预览与完成检查

公开版 0.4.7.1 · 仅插件与说明书，不附带提取角色图片、共享素材库、案例或本地测试工程。

从 镜头 → 预览当前场景 主动进入。插件会复制当前舞台到独立的 World3D，保留正式资源不被测试中的行走、旋转观察或音乐状态改写。它不是另一个场景编辑器。

窗口上的控件

逐步指南使用案例 07 的实际预览窗口。预览复制当前已应用场景；有未提交草稿时，先返回相应模块应用。

控件 / 操作 默认与范围 作用
锁定角度并跟随 默认勾选；也会使用镜头页的测试模式选择 勾选恢复正式朝向、俯角和角色跟随；取消可自由观察。不改变已保存镜头参数。
暂停循环 初值取当前舞台暂停状态 只暂停测试副本的循环，不回写源场景。音乐是否暂停由音乐配置决定。
速度滑块 -20～20 米/秒，步长 0.1，初值取源场景 即时修改测试副本滚动速度，负数反向，0 停止。正式速度在镜头页应用。
WASD / 方向键 鼠标焦点在预览窗口 控制基础角色移动；失去窗口焦点会停用移动输入，避免后台误走。
左键拖动 自由观察时 围绕焦点旋转镜头；不会补出精灵背面。
中键 / 右键拖动 自由观察时 平移观察镜头。
鼠标滚轮 自由观察时 拉近或拉远观察。
状态提示 只读 随模式显示行走或自由观察操作说明。
窗口关闭按钮 原生窗口按钮 立即停止该预览音乐并销毁副本；不把当前位置、镜头或速度保存回来。

一次完整的用户检查

  1. 先应用各页面参数并保存，打开预览。
  2. 向各个已有素材方向移动：脚底不漂、动作不被错误方向替换；缺失朝向的回退提示符合现有素材。
  3. 在小坡上走，检查碰撞和脚下阴影。平地投影阴影不适合任意斜坡。
  4. 让角色经过植物前后，检查遮挡；前景不能一直挡住脸。
  5. 循环舞台检查段边界：正向、反向、暂停、改速后都不应出现明显空洞。图像内容本身仍要做连续布局。
  6. 解锁镜头观察，再锁定，确认恢复正式构图；随后关闭预览，源场景对象不应跟着移动。
  7. 音乐至少听完一圈，检查 ♪ 曲目、音量、循环终点与接缝。预览和试听不要叠放；关闭窗口应停止声音。
  8. 修改正式场景后，重开预览刷新副本。真正运行当前场景可用 F6，正式项目主场景用 F5。

已知边界与排错

预览不显示刚修改的环境：它是打开时的快照，应用正式参数并重开。没角色：检查当前角色的 Profile / SpriteFrames 是否有真实帧。只有一个朝向：缺失素材不会生成；自由观察也不能把平面变成立体。渲染器的真实景深限制同环境页，屏幕分区虚化不是深度效果。
