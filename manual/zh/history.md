# 03 · 案例与历史资源

> **GitHub 公开版说明：**下文保留 0.4.6 原学习版说明。三位游戏提取角色预设、可选共享素材库与历史案例包未随公开版提供；内置建筑与地表已包含，角色可使用自己的素材。[查看分发说明](../DISTRIBUTION.md)

`03_HD2D_0.4.6_Case_Assets.zip` 包含案例 1–5 成品及其完整依赖，沿用 0.4.5 资源，不重新生成。案例 6 仍保留在旧版独立大地图包。

先安装第一包插件，再将第三包中的 `showcase`、`case01`、`local_study` 放入工程根目录，保留相对路径。案例不要求安装第二包共享库。更新已有工程前先备份同名文件。

| 案例 | 场景路径 |
| --- | --- |
| 1 · 油菜花田 | `res://showcase/Case01_Canola.tscn` |
| 2 · 白花松林 | `res://showcase/Case02_Lily.tscn` |
| 3 · 金穗原野 | `res://showcase/Case03_Grain.tscn` |
| 4 · 竹林花径 | `res://showcase/Case04_Bamboo.tscn` |
| 5 · 江南城镇 | `res://showcase/Case05_Jiangnan.tscn` |

等待 Godot 导入后，双击场景文件，选中场景根节点，在插件中继续编辑。保留场景旁的地形资源以及素材目录；运行用 F6，主动预览入口位于镜头模块。

本轮验收只覆盖插件和共享库，案例未重新运行测试。案例制作过程的历史教程仍在 `01_HD2D_0.4.5_Plugin_Manual.zip`；当前插件操作以本版功能参考为准。
