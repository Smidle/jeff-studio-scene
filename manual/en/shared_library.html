02 · Shared Asset Library

Public 0.4.7.1 · Plugin and manual only. No extracted character sheets, shared-library payloads, cases or local test projects are bundled.

0.4.7.1 ships the plugin and manuals only. The following is a reference for existing separate resource packages; these resources are not bundled and do not need reinstalling.

File: 02_HD2D_0.4.6_Shared_Asset_Library.zip. Install package 01 first, extract this library outside the project, then use Location… → HD2D_Shared_Asset_Library → Recheck at the top of the plugin.

Keep preset-index.json beside presets, terrain-index.json beside terrain, and character-index.json beside characters. Retain .gdignore. Back up existing libraries and preserve custom entries.

Choose models in Asset Workbench → Presets. For full-resolution terrain, use Surface Textures → Surface Source → Shared Originals / Extensions. Browsing loads only indexes and current-page thumbnails; selected dependencies are prepared for preview and use. Fully prepared, saved assets use project-local files.

Built-in buildings, terrain and characters remain available without a shared library. For connection failures, check the selected directory level and the status tooltip, then Recheck after repairing the path.

The package preserves existing resources and local-study provenance. Extracted artwork is not covered by the plugin MIT license. Case scenes are supplied separately in package 03.
