Jeff Studio Scene 0.4.7

Public 0.4.7 · Plugin and manual only. No extracted character sheets, shared-library payloads, cases or local test projects are bundled.

0.4.7 focuses on day/night and weather, adds six built-in architectural styles and Blender export, and improves town layouts, leaves/petals and character placement. Changes since 0.4.6.

This release contains the plugin and manuals only. Shared libraries, cases, local forests and test projects are excluded. The plugin includes nine architectural styles, 10 categories / 46 functional building types, 35 original surface textures and 14 schemes. The local-study package retains its three existing character presets; the public GitHub package excludes extracted character artwork and indexes.
